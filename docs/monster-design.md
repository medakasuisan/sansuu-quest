## 設計原則（確定済み）

- ゲーム層は**単元非依存**。通貨は「ゲットボール」（正解で入手）と「がくしゅうアメ」（レベルアップ用）の 2 つのみ
- 単元の色付けは**タイプ制**: わり算=「もりタイプ」（v1）。かけ算=「かざんタイプ」、筆算=「どうくつタイプ」は将来エリアで追加
- ○✗は正直につける。✗の帰結は「ボールが出ない」だけの**罰ゼロ設計**
- v1 = 収集+育成のみ（バトルなし）。図鑑 12 体コンプで次エリア（かざん）のロック解除演出

## 画像生成仕様

- **共通スタイルヘッダー**（全 12 体のプロンプト先頭に固定・画風統一のため）:

```
かわいいデフォルメ2頭身のオリジナルモンスターのキャラクターデザイン。
パステル調、やわらかい水彩タッチ、白背景、全身、正面向き、大きなキラキラの瞳。
子ども向け知育ゲームのキャラクター。正方形の構図、キャラクターを中央に大きく配置。
```

- 出力: 1024×1024 目標（Codex 出力が縦長の場合は後処理で正方形トリム）
- 後処理: リサイズ（表示用 512px）→ WebP 化 → base64 で HTML に埋め込み（Artifact は外部リソース不可のため）
- 保存: `assets/monsters/{番号}_{名前ローマ字}.png`（原本）+ 軽量化版

## 生成ワークフロー

1. 本設計書に佐々木さんの OK
2. Claude が Codex CLI へ 12 体分を順次投げる（`--sandbox workspace-write`・作業 dir = scratchpad）
3. 仕上がり 12 体を一覧で佐々木さんに提示 → リテイク指定（あれば個別再生成）
4. OK 分を後処理して `assets/monsters/` へ commit
5. ゲーム層実装（別途）
