# さんすうクエスト v4 設計書 — 「かずのもり」

> 2026-07-18 佐々木さん壁打ち確定分。目的 = **子どもがもっと勉強したくなるアプリ**にする。

## 確定した変更

### 1. ボール削除(通貨をアメ一本化)
- ゲットボールは廃止。正解のごほうびは**がくしゅうアメのみ**
- 出会いフロー: 2〜3問正解ごとに「モンスターが きみを みている…」→ タップ「なかまに なる!」→ 必ず仲間になる
- 「捕まえる」ではなく「**なかよくなる**」。ボール演出・🎯バッジ・intro のボール文言をすべて除去
- セーブデータ: `sq_save_v2` に移行(v1 から balls を捨てて自動マイグレーション)

### 2. 世界観「かずのもり」
- コンセプト: **こたえのひかりで モンスターが育つ森**。もんだいに こたえると「こたえのひかり」が生まれ、アメ(がくしゅうアメ)になる
- **まちがえても「かんがえたひかり」が森に灯る**(罰ゼロ設計の物語化)。✗のとき、小さな淡い光の演出+「かんがえた ひかりが もりに ともったよ」の一言
- ガイドキャラ **ルミはかせ**(ランタンを持ったモグラの博士)を新造。intro・コンプ演出・ミッション提示の案内役。画像は Codex 生成(GUIDE_IMG 差し替え口)
- 図鑑に**フレーバーテキスト**(1〜2行・ひらがな多め)を全12体に付与
  - 例: ワケルン「わけっこが だいすき。しっぽも 2つに わかれちゃった。」
  - 例: アマリン「あたまの しずくは たいせつな たからもの。」

### 3. あいことば → QRセーブ
- QR生成コードを**インライン実装**(外部CDN・通信なし)
- QRの中身 = `ARTIFACT_URL + '#sq=' + セーブコード` → タブレットのカメラアプリでスキャン→ブラウザが開いて**自動復元**(アプリ内カメラ不要)
- 起動時に `location.hash` の `sq=` を検出したら復元→確認表示→hash をクリア(history.replaceState)
- テキストコードのコピー/貼り付けも**保険として残す**(小さく)
- コード形式は `SQ2-`(balls なし)。旧 `SQ1-` の貼り付け復元も受理(後方互換)
- ARTIFACT_URL = `https://claude.ai/code/artifact/cfec9858-f1d3-4498-9322-9cd383347105`

### 4. 相棒ホーム常駐
- ホーム画面に相棒モンスター(いちばんレベルが高い子。同率なら最後に仲間になった子)を大きく表示+あいさつ吹き出し(ランダム数種)
- まだ0体のときはルミはかせが「もりへ いこう!」と誘う

### 5. アメを「たべさせる」操作に変更
- 自動XP吸収を廃止。正解で貯まったアメは**インベントリ**に入る
- ホーム/図鑑でモンスターをタップ→「アメを あげる」→ その子(のライン)に xp+1、もぐもぐ演出+ジングル
- まとめ食べ(「ぜんぶ あげる」)ボタンも用意(連打の手間を回避)
- クエスト結果画面に「アメを あげにいく」ショートカット(あげ忘れで成長停止を防ぐ導線)
- レベル/進化のしきい値は現行のまま(Lv5/Lv10)

### 6. 12体コンプ→解禁演出
- 12/12 到達でルミはかせのお祝い+「かざんへの ちずのかけら」入手演出
- かざんエリアのカードは「じゅんびちゅう。たのしみに!」の**正直な表現**(未実装の単元を開けたと誤解させない)

### 7. きょうのミッション(日替わり1個)
- 日付キーで小プールから1個(例:「きょう 3もん せいかい しよう」)。達成でアメ+3
- **未達ペナルティなし・翌日リセット**。ホームに小さく表示

### 8. おうちのひと画面
- フッターの「おうちのかたへ」リンクから遷移
- 日別の学習記録(日付・単元・解いた数・正答率)を直近14日ぶん localStorage に記録・表示
- 大人向けの通常表記(漢字OK)。つまずき傾向(あまり忘れ等)は将来拡張

## 変更しないもの
- 数学ロジック(Generators/CURRICULUM/selfTest)は不可侵
- 単一ファイルHTML・外部リソース禁止・スマホ/タブレット最適化・正解演出
- MONSTER_PNG(12体画像)・レア出現条件・レベル設計
