## §4. Phase 3 プロンプト — 画像生成（Codex CLI）

> Codex は**画像生成専用**。コードは書かせない。ChatGPT Plus 枠・実測 約43k tokens/枚・1〜3分/枚。
> 稀に API 待ちで28分級のハングが起きるため、**watchdog 8分つきバッチが必須**（実測レシピ）。

### 4-1. バッチ構造（オーケストレータが scratchpad に用意する）

```bash
#!/bin/bash
# gen_images.sh — 生成済みスキップ + watchdog 8分。リテイクは該当pngを消して再実行するだけ
OUTDIR="{SCRATCHPAD}/gen_out"; mkdir -p "$OUTDIR"
gen_one() {  # $1=出力名 $2=プロンプトファイル
  [ -f "$OUTDIR/$1.png" ] && { echo "skip: $1"; return 0; }
  timeout 480 codex exec --sandbox workspace-write -C "$OUTDIR" \
    "$(cat "$2") 出力ファイル名は $1.png としてカレントディレクトリに保存してください。" \
    || echo "TIMEOUT/FAIL: $1 (リテイク対象)"
}
# 以下、1体1行で列挙(呼び出し間に sleep 1)
```

### 4-2. モンスター画像プロンプト（1体ぶんのテンプレート）

```
かわいいデフォルメ2頭身のオリジナルモンスターのキャラクターデザイン。
パステル調、やわらかい水彩タッチ、白背景、全身、正面向き、大きなキラキラの瞳。
子ども向け知育ゲームのキャラクター。正方形の構図、キャラクターを中央に大きく配置。
{AREA_STYLE_LINE}
このモンスターの設定: {MONSTER_CONCEPT_FROM_DESIGN_DOC}
```

- 1行目〜3行目は**固定**（全エリア共通・画風統一のため変更禁止）
- `{AREA_STYLE_LINE}` はエリア色指定（§7 パラメータ表）。例(かざん):「火山・マグマ・あたたかい色(赤・オレンジ・金)を基調にする。」
- `{MONSTER_CONCEPT_FROM_DESIGN_DOC}` は monster-design.md の該当行を**そのままコピペ**（要約しない）

### 4-3. シーン絵プロンプト（1枚ぶんのテンプレート）

```
子ども向け絵本の1場面のイラスト。パステル調、やわらかい水彩タッチ、横長の構図。
文字は入れない。キャラクターの顔は小さめ・風景主体。
場面: {SCENE_DESCRIPTION_FROM_BIBLE}
```

- `{SCENE_DESCRIPTION_FROM_BIBLE}` は bible §3 シーン絵リストの該当行をそのままコピペ

### 4-4. 後処理（オーケストレータ or Sonnet 委譲。python3 + Pillow）

```
各 png について: 正方形センタートリム → 512px リサイズ → WebP(quality 80) 保存
→ 原本 png / webp を assets/monsters/ (連番_ローマ字名) と assets/scenes/ に保存 → commit。
base64 埋め込みは Phase 4 実装係の仕事(このPhaseではファイル保存まで)。
```

**受領後のゲート**: 佐々木さん目視で全画像 OK/リテイク指定 → リテイク分は png 削除して再実行（1周で済む構造）。
