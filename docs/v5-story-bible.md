## 6.5. つまずき傾向の記録(v5同梱・2026-07-18 佐々木さん確定)

- **目的**: おうちのひと画面で「どこでつまずいているか」を保護者に見せる
- **記録単位**: 採点のたびに、単元・問題タイプ(計算/等分除/包含除・あまり有無)・正誤・**ミス分類**を集計値として記録
- **ミス分類**(正解値と入力値の比較で機械判定):
  - `remainder-forgot`: 商は正解・あまり欄が空(=0扱い)で実際は あまり>0 → 「あまりの書き忘れ」
  - `remainder-wrong`: 商は正解・あまりが不正解 → 「あまりの計算ミス」
  - `quotient-off1`: 商が±1ズレ → 「九九のさがしすぎ/たりなさすぎ」
  - `quotient-wrong`: その他の商ミス → 「商のミス」
  - `word-setup`: 文章題での商ミス(式立ての可能性) → 「文章題の式立て」
- **保存**: 新キー `sq_miss_v1`(累計カウンタ・問題タイプ×分類のマトリクス)。個別の問題文・入力値は保存しない(集計のみ)
- **表示**: おうちのひと画面に「つまずき傾向」セクション追加。件数上位から日本語ラベルで表示(0件なら「目立ったつまずきはありません」)。既存の「今後の拡張で対応予定」の注記は削除
- **QRセーブには含めない**(端末ローカルのみ・学習ログと同格)
