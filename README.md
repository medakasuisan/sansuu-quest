# さんすうクエスト｜わり算

わけて わかる、わり算のぼうけん。3年生の割り算（あまりなし・あまりあり）を、九九ベースの解説つきで練習するブラウザゲーム。

- 単体HTML（vanilla JS / 依存ライブラリなし）
- 進捗は localStorage に保存（**進捗データはサーバーに送信しません**）
- 利用状況の把握のため Google Analytics (GA4) へ匿名の利用統計を送信（どの単元を遊んだか・正解数など）。
  **なまえ・入力したこたえ・もんだいの内容・セーブデータは送信しません**
- スマホ・タブレット対応

> 計測がブロックされている環境（オフライン・広告ブロッカー等）でもゲームは完全に動作します。

## 動作確認

```
cd sansuu-quest && python3 -m http.server 8000
# open http://localhost:8000/
```
